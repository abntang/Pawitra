# **Pawitra**

<p align="justify">
Pawitra is a digital platform and web application designed to showcase historical and geographical heritage elements, blending clean modern aesthetics with an interactive user experience. This project aims to present cultural or historical information in an engaging, accessible, and structured digital format.
</p>

## **Preview**

![Pawitra Preview](src/imports/Preview.png)

## **Design Philosophy**

<p align="justify">
The interface adopts a minimalist and balanced design philosophy, prioritizing content clarity, intuitive navigation, and responsive layouts. Every component is thoughtfully crafted to ensure a seamless and comfortable browsing experience across both desktop and mobile screens.
</p>

## **Technology Stack**

* React
* Vite
* TypeScript
* Tailwind CSS
* Lucide React

## **Language Support**

* 🇬🇧 English

## **Getting Started**

Clone this repository and install the required dependencies to run the project locally.

```bash
git clone [https://github.com/abntang/Pawitra.git](https://github.com/abntang/Pawitra.git)
cd Pawitra
npm install
npm run dev
```
